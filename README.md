# ¿Funciona el PSA aquí?

Herramienta de diagnóstico de ocho preguntas sobre pagos por servicios ambientales (PSA), de Innovations for Poverty Action.

Las preguntas cubren cuatro bloques: condiciones locales, mecanismo, condiciones de implementación y sostenibilidad financiera. El resultado indica si el PSA puede ser el instrumento adecuado para un territorio y qué haría falta construir si todavía no lo es.

## Uso

`index.html` es una página autocontenida: un solo archivo HTML con estilos y lógica incluidos, sin dependencias de build. Se abre directamente en el navegador o se publica con GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).

Las respuestas se procesan en el dispositivo del usuario y no se transmiten a ningún servidor.

## Base de evidencia

La herramienta se apoya en la revisión [*From Local Lessons to Global Scale: Generalizing Evidence on Payments for Ecosystem Services*](https://poverty-action.org/local-lessons-global-scale-generalizing-evidence-payments-ecosystem-services-pes), que sintetiza más de 40 estudios.
